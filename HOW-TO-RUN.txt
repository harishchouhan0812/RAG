📌 TROUBLESHOOTING:
════════════════════

Problem: "Connection Error"
Solution: 
  - Wait 10 seconds for models to load
  - Refresh browser (F5)
  - Make sure backend shows "🎉 RAG Pipeline Ready!"

Problem: Backend won't start
Solution:
  - Check if port 8000 is already in use
  - Run: netstat -ano | findstr :8000
  - Kill that process or restart computer

Problem: "Module not found"
Solution:
  - Run: setup.bat again
  - Make sure venv is activated
  - Run: pip install -r requirements.txt

Problem: Models downloading slow
Solution:
  - This is NORMAL for first time!
  - Sentence Transformers: ~400MB
  - Takes 2-5 minutes
  - Subsequent starts: 5-10 seconds
